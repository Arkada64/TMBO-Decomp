Twisted Metal: Black Reloaded - player package
=============================================
1. Put your own PS2 BIOS file in the "bios" folder (not included).
2. Put the game image in "game" as TMBR.iso.
3. Run TMBR.exe, pick your options, press PLAY.

Options: HD textures (the community HD pack, needs a stronger GPU), 16:9 picture, fullscreen,
potato mode (native resolution for weak PCs). "PCSX2 settings" opens the emulator's own settings
(controllers, renderer ...).

The emulator is PCSX2 (https://pcsx2.net), unmodified, GPL-3.0: source at https://github.com/PCSX2/pcsx2.
Community patches by Aced14, val, Darkscorpius and the TM:BO revival community (https://tmbosvr.com).
