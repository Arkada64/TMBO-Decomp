# Credits

TMB-Reloaded is a preservation and modding project for *Twisted Metal: Black* and
*Twisted Metal: Black Online* (PS2). No game data is included in this repository; building it
requires your own legally obtained discs.

## Original game
- **Incognito Entertainment**: developer of Twisted Metal: Black and Twisted Metal: Black Online
- **Sony Computer Entertainment America**: publisher

All game code, data and trademarks belong to their respective owners.

## Decompilation this project is built on
- **[tmb_decomp](https://github.com/abelbriggs1/tmb_decomp)**: Abel Briggs and contributors
  (including Zweronz). The retail Twisted Metal: Black decompilation that this project's
  build system, headers, symbol names and matched code started from.

## Tools
- [splat](https://github.com/ethteck/splat): binary splitting
- [spimdisasm](https://github.com/Decompollaborate/spimdisasm): MIPS disassembly
- [m2c](https://github.com/matt-kempster/m2c): MIPS-to-C decompiler, used for first drafts
- [decomp-permuter](https://github.com/simonlindholm/decomp-permuter): automated near-miss matching
- [asm-differ](https://github.com/simonlindholm/asm-differ): assembly diffing
- [decomp.me compiler collection](https://github.com/decompme/compilers): historical PS2 compilers
- [ninja](https://ninja-build.org/) and the GNU binutils MIPS toolchain
